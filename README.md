# Уютный дом у моря

Лёгкий одностраничный лендинг в стиле «морского стекла», реализованный как Cloudflare Worker.  
Идеально подходит для презентации дома у моря или сдачи жилья в аренду.

## Возможности

- **Плавающий заголовок** с плавной «боючей» анимацией  
- **Карточка в стиле стекла** поверх полноэкранного фонового фото  
- **Кнопки из морского стекла** (Позвонить, WhatsApp, Погода, Воспроизвести/Остановить звуки)  
- **Онлайн-виджет погоды** (API Open-Meteo, без отслеживания местоположения)  
- **Процедурные звуки моря и чаек** через WebAudio (без внешних файлов)  
- Полностью **адаптивный** дизайн для десктопа, планшета и мобильных устройств

## Как задеплоить

1. Войдите в Cloudflare Dashboard и перейдите в **Workers & Pages → Create application**.  
2. Выберите **Workers** (не Pages) и загрузите файл `worker.js` из этого репозитория.  
3. Нажмите **Deploy** и получите URL вашего воркера (например, `https://your-project.your-account.workers.dev`).

## Настройка

- **Фоновое изображение**  
  Замените константу `BG_URL` в начале `worker.js` на прямую ссылку на нужную фотографию.
- **Телефон и WhatsApp**  
  Кнопки «Позвонить» и «WhatsApp» будут использовать номер, который вы введёте в текстовое поле на странице.
- **Регион погоды**  
  По умолчанию виджет показывает погоду над открытым Средиземным морем (широта 32.7, долгота 34.9).  
  Для другого региона измените значения `LAT` и `LON` в `worker.js`.
